# Link Bouquet (链接花束) 💐

> **把喜欢的链接包成一束花送给 Ta**
> 
> 平时给朋友发歌、文章、视频，最熟悉的动作就是复制链接，往聊天框里一扔：“这个你看看。”
> Link Bouquet 给这个动作加了点心思：把专门为对方挑选的内容藏进一束数字鲜花里，再把整束花送出去。

---

## ✨ 核心功能亮点

1. **2.5D 拟物化花束排列**
   - 采用几何极坐标与扇形弧度算法，卡片像花瓣一样围绕花束包装纸优雅散开。
   - 附带花茎（Stems）与花瓣微章（百合、玫瑰、郁金香、向日葵、雏菊）。
   - 随风飘落的花瓣粒子与悬停微动特效。

2. **多平台卡片支持与即时预览**
   - 支持 **Spotify**、**YouTube**、**Bilibili**、**Substack / 文章**、**GitHub** 等多种平台。
   - 悬停浮起卡片，点击打开弹窗预览或直接播放内嵌视音频。
   - 支持发件人给每张卡片附上悄悄话（Personal Note）。

3. **零后端无痕分享 (Serverless & Zero-DB)**
   - 使用 `lz-string` 将整束花的数据（卡片清单、留言、主题、收件人）直接压缩编码至 URL Hash 中。
   - 复制生成的链接发给任何朋友，对方无需登录、无需数据库，打开即可 100% 还原整束花。

4. **开箱仪式感（Unwrap Experience）**
   - 收到链接的朋友打开时，呈现的是绑着丝带的礼盒包装。
   - 点击 **“💌 拆开花束”**：触发和弦音效（Web Audio API）、彩色花瓣礼花彩带喷射（Canvas Confetti），花束徐徐盛开。

5. **多套唯美主题调色盘**
   - 勃艮第红酒 (Wine Ruby - 原版经典配色)
   - 午夜星辰 (Midnight Navy)
   - 复古森林 (Vintage Forest)
   - 落日玫瑰 (Rose Blush)
   - 暖阳麦浪 (Golden Sunset)

6. **一键生成高清花束海报**
   - 基于 `html-to-image`，支持将定制的花束一键渲染下载为高清 PNG 贺卡或朋友圈海报。
   - 支持生成二维码方便手机端扫码体验。
